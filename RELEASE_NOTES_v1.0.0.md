# v1.0.0 — software and data reproducibility release

Initial public release of the reproducibility software and numerical data.

This release contains:

- exact symbolic checks of travelling-wave and spectral formulas;
- independent static and finite-difference checks;
- padded Fourier-Galerkin time-dependent simulations and convergence controls;
- Fourier-tail and projection-error data;
- Jacobi-Galerkin generator diagnostics;
- generated vector figures and CSV data used by the reproducibility scripts.

The manuscript itself is not included in this release.
